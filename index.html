シニアITサロンえーる

スマホやパソコンの「困った」を、一緒に解決する教室です。

70代・80代の方を中心に、それぞれのペースで学べます。分からないところは、その場で何度でも聞けます。

Features

えーるの5つのポイント

POINT 1講師による授業・クラス制

ビデオや本を使っての自主学習形式ではなく、講師が授業を進めるクラス制だから、わからないところや質問したいところをすぐに聞いていただけます！

毎週受講していただく時間帯が決まっているので、予定も立てやすい。

ほかの受講生さんともパソコンを通して親睦が深まるのもクラス制ならでは！季節の折々に、お花見やお食事会、新年会なども開催されるので、楽しく受講していただけます。

POINT 2安心の月会費制

お支払い料金は各月ごとの月会費制です（13,500円＋テキスト代）。

週1回の授業に加え、授業の振替や再受講（1回）もでき、上記以上の金額をいただくことはありません。

POINT 3振替・再受講

忙しくて、受講できるかどうか心配・・・そんな方のための安心の受講システム。

＜振替＞基本クラスに都合が悪くて出席できない場合、同じ内容を行っている他のクラスがある場合は、そのクラスに振替えて受講していただけます。

＜再受講＞過去に受講した授業をもう一度受けられます（再受講は1回）。

POINT 4メッセージ・電話サポート

内容についていけるか心配・・・そんな方のために、こんなシステムもあります。

＜個別サポート＞事前にご相談いただければ個人的な問題にも対応します。町内会の経理・スマホ操作など授業の前や後の空き時間での質問も可能です。

＜電話問合せ＞ご自宅で復習していてわからない！エラーメッセージが出て動かない！そんな時はお電話でお問い合わせいただけます（授業中以外の時間）。

＜オンライン学習＞Zoomを使った質問対応も可能です（事前申し出のみ）。

POINT 5復習を前提にした授業組み立て

一度ですべてを覚えようと思わなくても大丈夫。「忘れて当たり前」を前提に何度も繰り返すような授業内容にしています。その代わり、学習内容は多岐に渡ります。IT社会を楽しく便利に過ごすための内容です。
